# PaceUp — Multi-page Marathon Project

## Pages
- `index.html` — simple home page
- `races.html` — race cards with search and filters
- `register.html` — registration form, validation, automatic fee summary
- `payment.html` — simulated checkout
- `dashboard.html` — saved registrations and remove option

## Run
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Use the top navigation to visit the other pages.

Keep all files in the same folder.

## Notes
This is a front-end student project. Registration data is stored in browser localStorage, not a server/database. Payment options are simulated; no real payment is processed. Never enter real card numbers, CVV, UPI PIN, or banking passwords. JSON, XML/DTD and TypeScript examples are included for coursework. Angular and a real HTTP POST backend still need to be added if the complete lab syllabus requires them.
